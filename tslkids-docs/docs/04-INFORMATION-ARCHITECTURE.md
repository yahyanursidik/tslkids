## Program Finder

Input yang direkomendasikan:

1. usia;
2. kebutuhan utama.

Usia:

- 4–6
- 6–7
- 8–13
- 14–15

Need:

- mulai belajar Qur'an;
- memperbaiki bacaan;
- tahfizh;
- private;
- Qur'an + diniyyah.

Output:

- recommended program;
- alasan ringkas;
- CTA detail program.

Program finder adalah recommendation aid, bukan diagnosis atau assessment akademik formal.

## Information Principle

Setiap halaman harus menjawab:

1. Saya sedang melihat apa?
2. Ini untuk siapa?
3. Apa manfaatnya?
4. Bagaimana prosesnya?
5. Apa yang harus saya lakukan selanjutnya?
