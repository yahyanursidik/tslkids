# 07 — UI/UX

## Experience Goal

Pengunjung harus memahami dalam waktu singkat:

1. TSL Kids adalah program Qur'an anak.
2. Ada beberapa program yang berbeda.
3. Program dapat dipilih berdasarkan usia/kebutuhan.
4. Ada CTA yang jelas.

## Homepage Composition

Jangan menggunakan "card soup".

Recommended composition:

```text
Editorial Hero
↓
Program Navigation
↓
Interactive Program Finder
↓
Learning Journey Diagram
↓
Real Learning Story
↓
Parent Partnership
↓
Teacher Trust
↓
FAQ Accordion
↓
Typographic Final CTA
```

## Hero

Avoid:

- SaaS split-screen generic;
- dashboard mockup;
- gradient;
- giant decorative illustration.

Prefer:

- typography-led composition;
- age markers;
- program labels;
- intentional asymmetry;
- limited accent graphics.

## Program Cards

Program cards boleh ada, tetapi tiga program harus mempunyai distinctive visual detail.

Wajib ada:

- age marker;
- program type;
- concise value;
- CTA.

Jangan memasukkan paragraf panjang.

## Mobile

Prioritas desain: 375–430 px.

Rules:

- CTA muncul sebelum scroll terlalu jauh;
- text line length nyaman;
- tap target ≥ 44px;
- navigation sederhana;
- tidak ada horizontal overflow;
- image tidak mendominasi layar pertama.

## Desktop

Gunakan whitespace dan editorial grid.

Max content width sekitar 1160–1240px.

## Form UX

Pendaftaran sebaiknya multi-step jika field panjang:

1. Data Anak
2. Kebutuhan Belajar
3. Pilihan Program
4. Orang Tua
5. Review

Validation harus jelas, bukan hanya warna merah.

## FAQ

Accordion semantic.

Jangan semua jawaban dimuat terbuka pada mobile.
