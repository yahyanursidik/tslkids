# 12 — SEO

## Objective

Website harus mudah ditemukan untuk intent seperti:

- belajar Qur'an anak online;
- tahsin anak online;
- guru Qur'an private anak;
- kelas Qur'an anak online;
- madrasah Qur'an anak;
- belajar diniyyah anak online.

SEO tidak boleh mengorbankan natural language.

## Per Page

Wajib:

- unique title;
- unique description;
- canonical URL;
- OpenGraph;
- Twitter metadata jika digunakan;
- structured heading;
- internal linking.

## Technical

- sitemap.xml
- robots.txt
- clean URL
- semantic HTML
- fast loading
- image dimensions
- optimized assets

## Structured Data

Pertimbangkan:

- Organization
- EducationalOrganization bila sesuai
- Course / EducationalOccupationalProgram jika secara semantic cocok
- FAQPage bila masih sesuai kebijakan search engine terbaru

Jangan memasang schema yang tidak sesuai content aktual.

## Content SEO

Program page harus memiliki penjelasan substantive.

Jangan membuat thin page hanya untuk keyword.

## URL

Gunakan URL Bahasa Indonesia yang jelas:

- `/program/quran-private/`
- `/program/madrasah-quran-anak/`
- `/program/madrasah-quran-usia-dini/`
