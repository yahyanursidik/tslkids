# 10 — Anti AI-Slop

## Objective

Website harus terlihat dibuat untuk TSL Kids, bukan template yang diganti logo.

Hallmark digunakan sebagai design quality guardrail.

## Banned Defaults

Hindari:

- blue/purple gradient;
- gradient text;
- glow;
- glassmorphism;
- blobs;
- random abstract SVG;
- excessive `rounded-3xl`;
- pill everywhere;
- dashboard mockup;
- bento grid tanpa kebutuhan;
- giant centered generic hero;
- card after card after card;
- generic icon-feature row;
- decorative Islamic pattern;
- arch;
- masjid generik;
- kitab palsu;
- tasbih;
- bulan dan bintang;
- lentera;
- random Arabic ornament;
- stock illustration anak yang tidak autentik.

## Copy Slop

Hindari frasa:

- solusi terbaik;
- pengalaman luar biasa;
- membuka potensi maksimal;
- masa depan gemilang;
- pendidikan berkualitas tinggi;
- metode inovatif revolusioner;
- dirancang khusus untuk kebutuhan Anda.

Gunakan informasi konkret.

## Layout Rule

Untuk setiap section, tanyakan:

> Apakah layout ini dipilih karena isi section, atau hanya karena template?

Jika hanya karena template, redesign.

## Hallmark Workflow

1. Build from brand brief.
2. Audit homepage.
3. Identify generic pattern.
4. Redesign weak sections.
5. Audit responsive.
6. Audit final.

Jangan menggunakan Hallmark untuk mengganti brand foundation.

## Visual Test

Screenshot halaman tanpa logo.

Jika masih jelas terasa sebagai TSL Kids dari warna, typography, hierarchy, program markers, dan content treatment, identitas berhasil.
