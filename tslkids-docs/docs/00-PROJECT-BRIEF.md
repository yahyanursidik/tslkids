# 00 — Project Brief

## Nama

**Tarbiyah Sunnah Learning Kids**

Short brand: **TSL Kids**

Domain: `tslkids.my.id`

## Latar Belakang

TSL Kids memiliki beberapa program pembelajaran Al-Qur'an untuk anak dengan rentang usia, kebutuhan, dan model belajar yang berbeda.

Website dibutuhkan agar orang tua:

1. memahami TSL Kids;
2. memahami perbedaan tiap program;
3. menemukan program yang paling sesuai;
4. memahami cara belajar;
5. memperoleh rasa percaya terhadap proses pembelajaran;
6. mudah melakukan pendaftaran atau konsultasi.

Website bukan sekadar brosur digital.

Website adalah:

> pusat informasi, discovery, trust, dan conversion untuk ekosistem program Qur'an anak TSL Kids.

## Tujuan Bisnis

- Meningkatkan clarity program.
- Mengurangi pertanyaan berulang kepada admin.
- Meningkatkan conversion pendaftaran.
- Meningkatkan trust orang tua.
- Membentuk brand TSL Kids sebagai program pendidikan Qur'an anak yang serius namun hangat.
- Menjadi foundation untuk pengembangan parent/student experience di masa depan.

## Brand Positioning

> Program pembelajaran Al-Qur'an dan ilmu diniyyah untuk anak, dilakukan secara online dengan pendampingan yang terarah, lembut, bertahap, dan sesuai usia.

## Brand Promise

**Belajar sesuai usia. Dibimbing dengan baik. Bertumbuh bersama Al-Qur'an.**

## Core Message

**Belajar Al-Qur'an. Sedikit demi sedikit. Bertumbuh sepanjang perjalanan.**

## Target Utama

Orang tua/wali anak usia sekitar 4–15 tahun.

## Success Metric

### Discovery
- pengunjung memahami tiga program utama;
- pengunjung menemukan CTA sesuai intention.

### Engagement
- interaction pada program finder;
- kunjungan detail program;
- FAQ usage.

### Conversion
- klik daftar;
- submit registration;
- klik konsultasi/admin.

### Technical
- Lighthouse Performance ≥ 95;
- Accessibility ≥ 95;
- Best Practices ≥ 95;
- SEO ≥ 95;
- CLS < 0.1;
- LCP < 2.5s;
- INP < 200ms.

## Scope V1

Termasuk:

- homepage;
- program directory;
- tiga detail program;
- cara belajar;
- pengajar;
- FAQ;
- tentang;
- pendaftaran;
- privacy;
- terms;
- SEO;
- analytics events;
- responsive design;
- purposeful animation.

Tidak termasuk V1:

- LMS;
- login siswa;
- pembayaran kompleks;
- student academic information system;
- parent portal;
- attendance management;
- realtime scheduling engine.

Fitur tersebut dapat dikembangkan sebagai aplikasi/sistem terpisah.
